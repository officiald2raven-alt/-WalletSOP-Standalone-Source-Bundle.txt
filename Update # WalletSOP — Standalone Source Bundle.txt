## .github/workflows/release-checksum.yml

```yaml
name: Release Checksum

on:
  push:
    tags:
      - "v*.*.*"

jobs:
  compute-checksums:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: "20"

      - name: Install dependencies
        run: npm install

      - name: Build
        run: npm run build

      - name: Compute SHA-256 checksums
        working-directory: dist
        run: |
          sha256sum index.html assets/*.js assets/*.css > CHECKSUMS.txt
          echo "---" >> CHECKSUMS.txt
          echo "Release: ${{ github.ref_name }}" >> CHECKSUMS.txt
          echo "Commit: ${{ github.sha }}" >> CHECKSUMS.txt
          echo "Rubric: v1.0" >> CHECKSUMS.txt
          echo "Date: $(date -u +%Y-%m-%dT%H:%M:%SZ)" >> CHECKSUMS.txt
          cat CHECKSUMS.txt

      - name: Upload CHECKSUMS.txt to GitHub Release
        uses: softprops/action-gh-release@v2
        with:
          files: dist/CHECKSUMS.txt
```

## src/lib/diagnostics.js

```js
// Pure client-side scoring logic. No storage, no network.

export const RUBRIC_VERSION = "v1.0";
export const RUBRIC_DATE = "2026-08-05";

export const DEVICES = [
  "Coldcard Mk3",
  "Coldcard Mk4",
  "Trezor Model T2",
  "Ledger Stax",
  "BitBox02",
  "Foundation Passport",
  "Other / Software Wallet",
];

export const SEED_AGES = ["Pre-2022", "2023", "2024+", "Don't know"];

export const ENTROPY_OPTIONS = [
  { value: "device_only", label: "Device TRNG only, no manual entropy" },
  { value: "mixed", label: "Mixed: some manual dice rolls plus device randomness" },
  { value: "dice", label: "Fully manual: dice rolls entered directly on device" },
];

export const BACKUP_MEDIUMS = [
  "Metal plate (stamped/engraved)",
  "Paper (handwritten)",
  "No physical backup",
  "Other",
];

export const RUBRIC_TEXT = `Rubric ${RUBRIC_VERSION} — ${RUBRIC_DATE}

Each sub-score starts at 100 and is calculated independently. Clamp 0-100.

A. Entropy
  +60 dice-based, 50+ rolls | +30 dice-based, 20-49 rolls | +10 dice-based, <20 rolls | -15 mixed | -40 device TRNG only
  [severity tag: Medium — Single Point of Failure]

B. Backup & Storage
  Base 100. -100 if seed phrase has ever existed as a digital file, cloud backup, password manager entry, photo, or been typed on any internet-connected device.
  [severity tag: Critical — Fatal Failure]

C. Access Control
  +30 BIP-39 passphrase in use | +20 multisig quorum in use | (no penalty for absence, only foregone points)

D. Operational Hygiene
  +10 firmware current / -10 firmware not current`;

export function getCategory(score) {
  if (score >= 80) return { label: "Strong", tone: "secure" };
  if (score >= 60) return { label: "Developing", tone: "warning" };
  if (score >= 40) return { label: "Needs Attention", tone: "warning" };
  return { label: "Critical", tone: "critical" };
}

export function diagnose(state) {
  const { entropySource, diceRolls, firmwareCurrent, passphrase, multisig, exposure, fingerprint } = state;

  // A. Entropy
  let entropyScore = 100;
  const entropyBadges = [];
  const entropyBreakdown = [];
  const rolls = parseInt(diceRolls) || 0;

  if (entropySource === "device_only") {
    entropyScore -= 40;
    entropyBadges.push({ tone: "warning", label: "Device-Only TRNG", tag: "Medium — Single Point of Failure" });
    entropyBreakdown.push("-40 Device TRNG only");
  } else if (entropySource === "mixed") {
    entropyScore -= 15;
    entropyBadges.push({ tone: "warning", label: "Mixed Entropy", tag: "Medium — Single Point of Failure" });
    entropyBreakdown.push("-15 Mixed entropy source");
  } else if (entropySource === "dice") {
    if (rolls < 20) {
      entropyScore += 10;
      entropyBadges.push({ tone: "secure", label: "Dice Entropy (<20 rolls)" });
      entropyBreakdown.push("+10 Dice-based, <20 rolls");
    } else if (rolls < 50) {
      entropyScore += 30;
      entropyBadges.push({ tone: "secure", label: "Dice Entropy (20–49 rolls)" });
      entropyBreakdown.push("+30 Dice-based, 20-49 rolls");
    } else {
      entropyScore += 60;
      entropyBadges.push({ tone: "secure", label: "Dice Entropy (50+ rolls)" });
      entropyBreakdown.push("+60 Dice-based, 50+ rolls");
    }
  }

  // B. Backup & Storage
  let backupScore = 100;
  const backupBadges = [];
  const backupBreakdown = [];

  if (exposure === "yes") {
    backupScore -= 100;
    backupBadges.push({ tone: "critical", label: "Digital Exposure Detected", tag: "Critical — Fatal Failure" });
    backupBreakdown.push("-100 Seed phrase exposed to internet-connected device");
  } else if (exposure === "no") {
    backupBadges.push({ tone: "secure", label: "No Digital Exposure" });
    backupBreakdown.push("No digital exposure reported");
  }

  // C. Access Control
  let accessScore = 100;
  const accessBadges = [];
  const accessBreakdown = [];

  if (passphrase) {
    accessScore += 30;
    accessBadges.push({ tone: "secure", label: "BIP-39 Passphrase Active" });
    accessBreakdown.push("+30 BIP-39 passphrase in use");
  } else {
    accessBadges.push({ tone: "warning", label: "Not Yet Hardened — No Passphrase" });
    accessBreakdown.push("Passphrase not in use — 30 points foregone (not a penalty)");
  }
  if (multisig) {
    accessScore += 20;
    accessBadges.push({ tone: "secure", label: "Multi-Signature Quorum" });
    accessBreakdown.push("+20 multisig quorum in use");
  } else {
    accessBadges.push({ tone: "warning", label: "Not Yet Hardened — No Multisig" });
    accessBreakdown.push("Multisig not in use — 20 points foregone (not a penalty)");
  }

  // D. Operational Hygiene
  let hygieneScore = 100;
  const hygieneBadges = [];
  const hygieneBreakdown = [];

  if (firmwareCurrent) {
    hygieneScore += 10;
    hygieneBadges.push({ tone: "secure", label: "Patched Firmware" });
    hygieneBreakdown.push("+10 firmware current");
  } else {
    hygieneScore -= 10;
    hygieneBadges.push({ tone: "warning", label: "Unpatched Firmware" });
    hygieneBreakdown.push("-10 firmware not current");
  }

  // Fingerprint (not scored, local validation only)
  const fpValid = /^[0-9a-fA-F]{8}$/.test((fingerprint || "").trim());
  if (fingerprint && !fpValid) {
    hygieneBadges.push({ tone: "warning", label: "Fingerprint Format Invalid" });
  } else if (fpValid) {
    hygieneBadges.push({ tone: "secure", label: "Fingerprint Validated" });
  }

  // Clamp all
  entropyScore = Math.max(0, Math.min(100, entropyScore));
  backupScore = Math.max(0, Math.min(100, backupScore));
  accessScore = Math.max(0, Math.min(100, accessScore));
  hygieneScore = Math.max(0, Math.min(100, hygieneScore));

  const fatal = backupScore === 0;

  const subScores = {
    entropy: { score: entropyScore, badges: entropyBadges, breakdown: entropyBreakdown, label: "Entropy" },
    backup: { score: backupScore, badges: backupBadges, breakdown: backupBreakdown, label: "Backup & Storage" },
    access: { score: accessScore, badges: accessBadges, breakdown: accessBreakdown, label: "Access Control" },
    hygiene: { score: hygieneScore, badges: hygieneBadges, breakdown: hygieneBreakdown, label: "Operational Hygiene" },
  };

  return { subScores, fatal };
}

export function buildRecommendations(result, state) {
  const { fatal, subScores } = result;

  if (fatal) {
    return {
      type: "migration",
      title: "Urgent Migration SOP",
      steps: [
        {
          text: "Generate a new seed using dice-based entropy (50+ rolls) entered directly on the device.",
          why: "The exposed seed must be treated as already compromised. Dice-based entropy removes the device manufacturer's RNG from your trust model, so the replacement seed's security depends only on fair dice and your rolling technique — not on any hardware you can't audit.",
        },
        {
          text: "Stamp the new seed onto a fireproof metal backup plate. Never photograph or type it.",
          why: "Metal survives house fires and water damage that would destroy paper. Any digital representation — photo, cloud sync, typed note — reintroduces the exact exposure that forced this migration, undoing the regeneration before it's even complete.",
        },
        {
          text: "Migrate your funds from the exposed wallet to the newly generated wallet.",
          why: "Funds left on the exposed seed remain at risk indefinitely — anyone who captured the digital copy can move them at any time. Migration transfers custody to a seed whose private material has never touched an internet-connected device.",
        },
        {
          text: "Retire and securely destroy the exposed seed material.",
          why: "An intact physical copy of the old seed is still usable by anyone who finds it. Physical destruction — not merely discarding — is the only way to guarantee the exposed material can't be recovered and used after migration.",
        },
      ],
      needsSeedRegeneration: true,
    };
  }

  const steps = [];

  if (state.entropySource === "device_only" || state.entropySource === "mixed") {
    steps.push({
      text: "For future seeds, consider dice-based entropy generation (50+ rolls) to remove single-point-of-trust dependency on device RNG.",
      why: "Device TRNG output can't be independently audited — you're trusting the manufacturer's implementation is sound and unbackdoored. Manual dice rolls let you verify the entropy source with your own eyes, collapsing a hidden trust assumption into a physical process you control.",
    });
  } else if (state.entropySource === "dice") {
    const rolls = parseInt(state.diceRolls) || 0;
    if (rolls < 50) {
      steps.push({
        text: `You used ${rolls} dice rolls. Consider 50+ rolls for future seeds to maximize entropy.`,
        why: "BIP-39 seeds target 128 bits of entropy as a minimum security threshold. Below ~50 fair six-sided rolls, the total combination space may fall short of that threshold — more rolls push you comfortably past it rather than leaving you near the edge.",
      });
    }
  }

  if (!state.passphrase) {
    steps.push({
      text: "Add a BIP-39 passphrase, stored separately from the seed backup.",
      why: "A passphrase acts as a 25th word — even if your seed phrase is ever found, photographed, or copied, funds can't be accessed without it. It's the single highest-leverage addition for a low ongoing burden, and it decouples 'finding the backup' from 'stealing the funds.'",
    });
  }
  if (!state.multisig) {
    steps.push({
      text: "Consider a multi-signature setup for additional key redundancy.",
      why: "Multisig requires multiple independent devices to authorize a transaction, so no single compromised key can move funds. It also tolerates the loss of one key without losing access to the wallet — turning a single point of failure into a quorum.",
    });
  }
  if (!state.firmwareCurrent) {
    steps.push({
      text: "Update device firmware to the latest patched build.",
      why: "Manufacturers publish firmware updates to close specific, identified vulnerabilities. Running an unpatched build means any publicly disclosed flaw in your firmware version is exploitable against your device as-is — updates close those gaps rather than leaving them open.",
    });
  }

  const needsSeedRegeneration =
    state.entropySource === "device_only" ||
    state.entropySource === "mixed" ||
    (state.entropySource === "dice" && (parseInt(state.diceRolls) || 0) < 50);

  return {
    type: "hardening",
    title: "Hardening SOP",
    steps,
    needsSeedRegeneration,
  };
}

          cy="75"

## public/sw.js

```js
// WalletSOP service worker — offline static-asset caching ONLY.
//
// What this does:
//   - Caches the app's own built static files (HTML, JS, CSS, icons) so the
//     app works fully offline after the first visit.
//   - Uses cache-first: serve from cache, fall back to network on a miss, and
//     cache the response for next time.
//   - On activation, deletes any previous cache version so stale scoring
//     logic is never served.
//
// What this does NOT do:
//   - No background sync, no push notifications, no telemetry, no analytics.
//   - No "check for updates" network ping — the browser manages SW updates.
//   - No cross-origin handling — requests to any other origin pass through
//     untouched and are never cached or inspected.
//
// This file is part of the auditable public source at:
//   https://github.com/walletsop/walletsop

const CACHE = "walletsop-v1";

// Core app shell — always available offline after install.
const CORE = [
  "/",
  "/index.html",
  "/manifest.json",
  "/favicon.svg",
];

self.addEventListener("install", (event) => {
  event.waitUntil(
    caches.open(CACHE).then((cache) => cache.addAll(CORE))
  );
  self.skipWaiting();
});

self.addEventListener("activate", (event) => {
  event.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(
        keys.filter((k) => k !== CACHE).map((k) => caches.delete(k))
      )
    ).then(() => self.clients.claim())
  );
});

self.addEventListener("fetch", (event) => {
  const req = event.request;

  // Only handle same-origin GET requests; everything else passes through.
  if (req.method !== "GET") return;
  const url = new URL(req.url);
  if (url.origin !== self.location.origin) return;

  event.respondWith(
    caches.match(req).then((cached) => {
      if (cached) return cached;
      return fetch(req).then((res) => {
        // Only cache successful, same-origin basic responses.
        if (res && res.status === 200 && res.type === "basic") {
          const copy = res.clone();
          caches.open(CACHE).then((cache) => cache.put(req, copy));
        }
        return res;
      });
    })
  );
});
```

## src/hooks/usePwaInstall.js

```js
import { useState, useEffect } from "react";

// Captures the browser's beforeinstallprompt event so any component can
// trigger the PWA install dialog on demand. Non-blocking: if the browser
// doesn't support installation, canInstall stays false and nothing renders.
export function usePwaInstall() {
  const [deferred, setDeferred] = useState(null);
  const [installed, setInstalled] = useState(false);

  useEffect(() => {
    const onPrompt = (e) => {
      e.preventDefault();
      setDeferred(e);
    };
    const onInstalled = () => {
      setInstalled(true);
      setDeferred(null);
    };
    window.addEventListener("beforeinstallprompt", onPrompt);
    window.addEventListener("appinstalled", onInstalled);
    if (window.matchMedia?.("(display-mode: standalone)")?.matches) {
      setInstalled(true);
    }
    return () => {
      window.removeEventListener("beforeinstallprompt", onPrompt);
      window.removeEventListener("appinstalled", onInstalled);
    };
  }, []);

  const promptInstall = async () => {
    if (!deferred) return;
    deferred.prompt();
    await deferred.userChoice;
    setDeferred(null);
  };

  return { canInstall: !!deferred && !installed, promptInstall };
}
```

## README.md

```markdown
# WalletSOP

A free, open-source, 100% stateless web app that performs a procedural security audit of
cryptocurrency cold-storage setups and produces an educational, printable Standard Operating
Procedure (SOP). This is diagnostic education, not mathematical verification of any specific
wallet or device.

## Absolute Rules

- Never asks for a seed phrase, private key, or any secret material.
- Never flags a specific device model + date combination as "compromised."
- Scoring is 100% deduction/addition based on documented best practices.
- Zero network requests. Zero backend. Zero data persistence, ever.
- No live connection to any physical hardware wallet (no WebUSB/WebHID).
- Self-report only — the tool cannot and does not claim to verify anything it's told.

## Quick Start

```bash
npm install
npm run dev
```

## Run Fully Offline

To independently verify zero network calls:

```bash
npm run build
```

Then disconnect from the internet and open `dist/index.html` directly in your browser, or serve
the `dist/` folder locally:

```bash
npx serve dist
```

With the internet disconnected, the app will function identically — all computation happens
client-side.

## Build Checksum

Each tagged release publishes a SHA-256 checksum of its build output, computed by CI at
release time — never hand-written. Find the checksum for a given version in that release's
GitHub Release notes, or recompute it yourself:

```bash
npm install
npm run build
sha256sum dist/index.html dist/assets/*.js dist/assets/*.css
```

Compare the output against the checksum listed on the corresponding GitHub Release page. A
mismatch means you are not running the code from that release — inspect the source before
trusting it.

## Rubric Version

Current rubric: **v1.0** (2026-08-05)

The scoring rubric is versioned and dated. Any future changes to scoring weights will be
tracked in the changelog below and the version number will increment.

### Changelog

- **v1.0** (2026-08-05): Initial rubric. Four independent sub-scores (Entropy, Backup &
  Storage, Access Control, Operational Hygiene). Fatal exposure path in Backup & Storage.

## Install as an App (PWA)

WalletSOP is installable as a Progressive Web App. Once installed, it runs from
a home-screen or desktop icon and works fully offline — no browser, no
internet connection, no Node.js, no command line required.

**This is functionally equivalent to the "Run Fully Offline" instructions
above**, but without needing to clone the repo or run a build yourself.

### What gets cached

- Only the app's own built static files: `index.html`, the bundled JS and CSS,
  `manifest.json`, and `favicon.svg`.
- Caching happens locally in your browser's storage after your first visit.
  A cache-first strategy serves these on every subsequent load — offline.

### What does NOT get cached (or sent anywhere)

- Nothing about you, your answers, or your audit. The app remains 100%
  stateless — no data is ever stored, transmitted, or persisted.
- The service worker never makes background sync, push, telemetry, analytics,
  or "check for updates" network requests.
- No cross-origin request is ever cached or inspected — the worker only
  handles same-origin GET requests for the app's own static assets.

### Inspectability

The service worker (`public/sw.js`) and manifest (`public/manifest.json`) are
part of the auditable public source in this repository, alongside everything
else. Read them yourself before installing.

### Header banner wording

The in-app header reads "100% Stateless. No data ever leaves your browser."
This refers to user data and scoring logic — no information about you or your
audit is ever sent anywhere. The one-time static-asset caching a PWA install
performs is a separate, local, inspectable operation that fetches only the
app's own files; it does not contradict the stateless claim.
